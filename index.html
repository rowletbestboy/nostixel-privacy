1. Introduction

This policy describes how Sergrudolf Arago handles information in the Nostixel Android application ("Nostixel"). Nostixel is an emulator that lets users select game files and play them locally. This draft reflects the audited application behavior as of the effective date above.

2. Scope

This policy applies to the Nostixel Android app. It does not govern the independent privacy practices of Android, Google Drive, a document provider, or a service a user chooses in Android's system file picker.

3. Information Nostixel accesses and stores

Nostixel does not require an account or ask users for a name, email address, phone number, payment details, location, contacts, or other profile information. In the reviewed release, no app-controlled server, analytics, advertising, authentication, or remote crash-reporting service was identified. The release manifest has no Internet permission. These findings describe the reviewed release and should be checked again if the app or its dependencies change.

Nostixel processes files users choose to import and creates local records needed for its features. Local processing is different from the app transmitting that information to a Nostixel server or another company.

4. Information stored on the device

Nostixel stores data in app-private storage, including:

  • imported ROM files, filenames, file paths, and content hashes;
  • ROM library metadata, including titles, favorites, play time, last-played values, and identifiers used to associate game data with a ROM;
  • cartridge save files, manual save states, and resume save states;
  • user-entered cheat names, codes, and enabled status; and
  • preferences such as video, audio, control, and player settings, including the selected ROM path and identity.

Nostixel uses the app version for display in Settings. No persistent device identifier was found. The application does not implement a separate encryption layer for these local files or its SQLite database; Android's app sandbox and device protections apply.

5. ROM files and imported content

When a user selects a .gba file or supported ZIP archive, Nostixel copies the selected ROM into its private app storage for gameplay. Nostixel does not provide ROM downloads, bundle game ROMs in the reviewed release, or intentionally upload ROMs to Nostixel servers. Users are responsible for ensuring they have the rights to select and use their files.

The Android system file picker can show local and cloud-backed storage providers. If a user browses to and selects a file from a cloud-backed provider, that provider may retrieve or otherwise process the file as part of the user's selection under that provider's own terms and privacy policy. This is a user-initiated provider action, not an upload by Nostixel.

6. Save files and save states

Cartridge save files and emulator save states are stored locally in Nostixel's app-private support storage and database. Nostixel does not implement cloud save synchronization.

7. Device and diagnostic information

Nostixel does not request device identifiers or location. Performance instrumentation and error handling can write metrics, exception details, or stack traces to local device logs. Such messages are not sent by Nostixel to a remote diagnostics service. A local error may contain a ROM path or filename; users should avoid posting device logs publicly if they contain personal information.

8. Internet and network communication

The inspected release has no android.permission.INTERNET permission and no app-controlled network request was identified. The debug and profile development manifests include Internet permission for development support; that permission was absent from the inspected release artifact.

9. Android device backup and transfer

Nostixel is configured to disable Android Auto Backup and exclude app data from supported cloud-backup and device-to-device transfer paths. The Android manifest sets android:allowBackup="false" and references exclusion rules for supported older Android versions and Android 12 and later. Those rules exclude the app's files, databases, preferences, and other configured app-data domains. The Android 12+ rules also configure exclusions for the cross-platform-transfer path on Android versions that support it.

Nostixel does not intentionally upload ROMs, save files, save states, cheats, preferences, or other app data to Nostixel servers. These Android settings are not an absolute guarantee for every manufacturer: some OEM device-to-device migration behavior may not honor allowBackup=false, and manufacturer migration tools outside Android's documented backup-rule system may behave differently. Cross-platform-transfer rules apply only on Android versions that support them. This policy should be reviewed again if the Android configuration or platform behavior changes.

Because Nostixel does not back up or transfer app data, users who change devices or reinstall the app will need to import their ROMs again and manually recreate or restore other local data themselves.

10. Third-party libraries and services

Nostixel includes Flutter and open-source packages for navigation, local storage, file selection, audio output, and Android integration. The review did not identify a third-party SDK that sends personal data, analytics, ads, or crash reports. Settings > About includes bundled mGBA and inih license notices and a Flutter/package license page. Android, Flutter, the file-picker integration, and other open-source components may process information locally to provide app features. Android's system file picker and cloud-backed providers are described above. This review does not replace the independent privacy terms of those platforms or providers.

11. Data sharing

Nostixel does not implement an app-controlled data-sharing or upload feature. Nostixel does not intentionally upload ROMs or save data to Nostixel servers. User-initiated selection through an Android document provider is handled as described above. Android backup and supported transfer paths are disabled or excluded, subject to the manufacturer limitations described above. No other app-controlled sharing flow was identified in the reviewed release.

12. Retention and deletion

Nostixel keeps data in app-private storage until it is removed. Users can delete some save states and cheats in the app, but the reviewed version does not provide an in-app action to delete an imported library ROM or clear all Nostixel data. Users can clear the app's storage or uninstall it through Android settings; those actions remove Nostixel's app-private data. They do not delete the original file from a separate local or cloud-backed provider.

Nostixel has no app account or developer server-side user record. Android cloud backup and supported device-to-device transfer are disabled or excluded, subject to the platform limitations described above. Nostixel does not provide backup restoration. Users changing devices or reinstalling must import their ROMs again and manually recreate or restore other local data. If the publisher later adds an account or remote data service, this section and the Google Play disclosures must be updated before release.

13. Security

Nostixel stores its data in app-private Android storage. The review found no custom encryption of the local database, imported ROMs, or save files, and this policy does not promise that they are encrypted at rest. Android's app sandbox and the device's own security settings apply. Nostixel's Android backup and transfer exclusions are described above, including their manufacturer limitations. No security measure can be guaranteed to prevent every risk.
